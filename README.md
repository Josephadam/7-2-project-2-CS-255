<strong>How did you interpret the user’s needs and implement them into your system design? Why is it so important to consider the user’s needs when designing?</strong>
Its important to impliment user needs because they are the one using the system and to interpret the user's needs, I focused on understanding their goals, pain points, and expectations through feedback, surveys, and user stories. I then used this information to prioritize features that would enhance usability and ensure the system is intuitive and accessible.
It's important to implement user needs because the users are the ones interacting with the system daily. If their needs aren’t met, the system may be inefficient, confusing, or underutilized. By designing with the user in mind, we create solutions that are more functional, user-friendly, and ultimately more successful in achieving their intended purpose.
